V40.28 靜讀書房驗收

先確認閱讀器顯示 v40.28。本頁用來確認 A＋B 改版及既有引用相容性。
開啟閱讀器 · 完整更新與上傳說明 · 驗證摘要

閱讀與外觀

  1. 在「設定」切換原書、18px、20px及行距，再測七級字級與重設；確認仍看見原本的明體、楷體、粗斜體與底線差異。
  2. 於長段中改字級／行距，關閉設定後仍應回到原來內容；手機切換「更多／搜尋／字級」後位置也應保留。
  3. 切換亮色、暗色、跟隨系統；檢查正文、選中目錄、搜尋、註文、分享與資料面板。
  4. 第十四章第六節末右箭頭應往第七節；詞彙導覽亦只前進一個詞條。

資料、鍵盤與浮層

  1. 在本機測試網址建立書籤和閱讀分頁，匯出完整備份；匯入應先顯示內容預覽，明示合併或取代。取消匯入不得改資料。
  2. 重複匯入、空清單、無效檔案和儲存受限要有正確結果；需要完整還原時使用取代。請先保留自己的匯出檔。
  3. 新增第六個分頁時應清楚處理滿額；移除或替換後可復原。使用 Tab/Enter 操作分享、關閉及分頁管理。
  4. 手機開引用鏈結後，再開更多、註文或朗讀；英文入口仍可用，引用控制不得遮住主要操作。Escape應先關最上層，焦點回到入口。

引文貼上

開下方案例，按「複製引文＋連結」，再貼到這裡或 LINE 草稿；應有引文、出處與網址。按「僅複製連結」則只有網址。本頁不會傳送文字。

離線與更新

在設定的「資料與離線」完成保存，斷網後重新開啟書籍與句子鏈結。新版由提示明確套用，更新後書籤與閱讀位置保留。若本機無法取得已驗證書籍，復原頁應提供重試與檢查更新。

本機網址不能用來給別人的手機分享。正式站上傳後，請以 iOS／Android 實際 LINE 與已安裝 PWA 再確認。
