V40.29.1 引文複製驗收

V40.29.1 本次驗收

  1. 先匯出目前完整備份；匯入後應先出現預覽，按取消不變動資料。
  2. 選擇合併或取代後確認，應顯示已確認持久保存；重新開啟後書籤、分頁及目前分頁均正確。
  3. 匯入舊版備份、空清單、跟隨系統模式；不完整或損壞 JSON 應明示失敗且不變動資料。
  4. Android Chrome／主畫面 App 原生長按選句並拖曳選取把手，分享列應迅速出現並跟隨目前選取內容；點分享後複製引文＋連結，再貼至 LINE。
  5. 沿用下列舊鏈結與英文原典對照測試。實機速度請以正式更新套用後確認。

本測試頁不讀寫正式閱讀資料。資料只由閱讀器自身的操作處理。

本頁驗證「複製後貼到訊息」的文字內容。請先確認閱讀器版本為 v40.29.1。
更新與上傳說明 · 開啟閱讀器
  1. 點下方任一句子，按接收端「複製引文＋連結」，回來貼到下方文字框，應含引文、出處、換行及繁中網址。
  2. 按「僅複製連結」再貼，應只有網址。
  3. 在正文選取句子或片語 → 分享 →「複製引文＋連結」，貼上應保留所選引文。引文中的註碼、朗讀按鈕文字不應被混入。
  4. 你可自行把複製的內容貼到 LINE 草稿確認。系統「分享…」的接收方式由平台決定；本頁不會代為傳送訊息。
